# 数字里的一二·九

交互式数据可视化（AI 创作大赛作品）。

## 模块
- 一 · 时间节点：ECharts 散点图，一二·九运动 10 个历史时间节点，核心 12-09 高亮
- 二 · 口号谱系：ECharts 关系图，四大口号及其历史指向（9 节点 / 5 连线）
- 三 · 精神传承：预留

## 技术
- ECharts 6.1.0（本地化，无外部 CDN）
- 数据：`src/data/events.json`（史实数据，10 时间节点 / 4 口号 / 6 影响）
- 字体：思源黑体 / Noto Sans SC（SIL OFL 开源，可商用）
- file:// 可直接打开，无跨域

## 运行
直接用浏览器打开 `src/index.html`（file:// 直开，无构建）。
